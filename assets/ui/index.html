WiFi 与定时
两条互相独立的「后台停扫」条件，任一命中就停：
· WiFi 场景：连上这个 WiFi 且信号不弱于该场景自己的门槛；
· 定时场景：在这个时段内（可跨夜，如 23:00 → 06:30）。
停扫期间不扫蓝牙、不做自动解锁/锁车，后台动作全停，这是最省电的状态。

每个场景一个 WiFi + 一个专属门槛。家里路由器信号强、公司 AP 弱，各设各的，不会一头误停一头白扫。
